# maturity-assessment-model
Инструмент, реализующий модель оценки зрелости практического применения фреймворков DevSecOps и Agile для повышения уровня кибербезопасности российских компаний

## Основные функции
- Аудит инфраструктуры (HTTPS, SSH, firewall, интеграции)
- Оценка уровня зрелости по 10 критериям
- Автоматическая генерация планов коррекции
- Выполнение Ansible плейбуков для исправлений
- Хранение отчетов в базе данных

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python run_demo.py
```

## Структура проекта
- `app.py` - основной оркестратор
- `audit.py` - модуль аудита
- `decision.py` - принятие решений
- `automation.py` - автоматизация с Ansible
- `database.py` - хранение отчетов
- `models.py` - модели данных
- `config.py` - конфигурация
